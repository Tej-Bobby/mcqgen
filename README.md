Libraries Needed:


| Library                 | Purpose                                               |
| ----------------------- | ----------------------------------------------------- |
| `langchain`             | Main framework for chaining prompts and LLM workflows |
| `langchain-community`   | Community integrations used by LangChain              |
| `langchain-huggingface` | Hugging Face support inside LangChain                 |
| `transformers`          | To load Hugging Face models                           |
| `torch`                 | Backend required for transformer models               |
| `huggingface_hub`       | Access Hugging Face models/API                        |
| `streamlit`             | Web UI for your MCQ app                               |
| `python-dotenv`         | Load API keys from `.env` file                        |
| `PyPDF2`                | Read PDF files                                        |
| `pandas`                | Store/export MCQs in table format                     |
